I

About the author

A short account of who is doing the building, and why.

❦

My name is Ahmad Andhika Haririe. I write software across an unusually wide field for one person: browser front-ends, PHP and JavaScript back-ends, Android and iOS applications from a single Flutter codebase, and 2D games in Godot. The through-line is not a framework — it is a preference for systems that a stranger can open six months later and still understand.

Most of what I have built started as a problem someone I know actually had. A workshop that lost bookings to a paper ledger became Bengkel Aja. A kitchen throwing away food became ZeroWaste. A small merchant who could not take QRIS payments became a point-of-sale app. The games came from wanting to know how the other half of the industry thinks.

I am comfortable owning a feature end to end — schema, API, interface, deployment — and I would rather ship something small that works than something large that demonstrates. At the moment I am spending my time on edge computing: this site, and the mail server behind my own domain, both run on Cloudflare's network with no origin server at all.

II

The craft

Four kinds of work I take on, and what you actually receive.

❦
  • 01

    Web applications

    Component-driven front-ends in React or Svelte, wired to a Laravel, Node or Workers back-end. Authentication, roles, live data, and an admin surface that a non-engineer can actually operate.

    React · Svelte · Laravel · Tailwind · Vite

  • 02

    Mobile applications

    One Flutter codebase, two stores. Offline-tolerant state, camera and barcode input, local notifications, and payment gateways wired up properly — including QRIS through Midtrans.

    Flutter · Dart · Firebase · Midtrans

  • 03

    APIs & edge services

    REST APIs with sane resources and honest status codes, plus serverless services on Cloudflare Workers backed by D1 and R2 — no origin box to patch, and a cold start you cannot measure.

    Workers · D1 · R2 · REST · MySQL

  • 04

    Games & interactive

    2D games in Godot 4: state-machine characters, boss encounters, wave systems and tower economies — exported to desktop and Android, with Python tooling where the editor stops being enough.

    Godot 4 · GDScript · Python
